# 📑 NoteVault

> **100% Offline-First, Zero-Knowledge Encrypted Markdown & Knowledge Base**
>
> Built with zero external runtime dependencies. Self-contained in a single, portable HTML file.

---

## 🌟 Key Features

* 🔒 **Zero-Knowledge Cryptography**: Everything is encrypted locally with **AES-256-GCM** using keys derived via **PBKDF2-HMAC-SHA256** (100,000 iterations). Plaintext notes never touch storage or network unencrypted.
* 🔑 **BIP39 Master Recovery Seed**: 12-word human-readable recovery phrase (from the standard 2048-word BIP39 dictionary) guarantees vault access and cross-device pairing.
* 📦 **100% Standalone & Offline**: Open `index.html` directly from your local filesystem (`file://`) or as an installable Progressive Web App (PWA). No node servers, no accounts, and zero tracking.
* 📱 **Mobile-Optimized UX**:
  * **1-Tap Mobile View Switcher**: `[ ✍️ Edit | 👁️ Preview | ◫ Split ]` for full-screen typing, full-screen reading, or live split views on phones.
  * **Touch-Friendly Drawer**: Slide-out navigation sidebar with gesture backdrop.
* 📜 **Bi-Directional Synchronized Scrolling**: Real-time proportional scrolling between Editor and Preview powered by a zero-latency mutual exclusion engine with dedicated toolbar toggle (`🔗 Sync Scroll`).
* ↔️ **Draggable Workspace Splitters**: Smooth draggable resizing for the Navigator Sidebar and Editor/Preview panes with `localStorage` persistence and double-click reset.
* 🎨 **Multi-Format Rendering**:
  * **Markdown**: GitHub-Flavored Markdown (GFM) tables, task lists, blockquotes, and inline code.
  * **JSON Tree**: Interactive collapsible tree with color-coded data types, search filtering with `<mark>` query highlighting, and one-click JSON path copying.
  * **XML**: Syntax-highlighted XML tags, attributes, and values.
  * **Mermaid**: Flowcharts and sequence diagrams rendered in ` ```mermaid ` blocks.
  * **Auto-Detection**: Automatic format recognition with manual toolbar override.
* 🔄 **Encrypted Cloud Sync via GitHub Gists**:
  * Syncs an end-to-end encrypted envelope (`vault.enc`) to a private GitHub Gist using your GitHub Personal Access Token (PAT).
  * Auto-syncs on typing, blur, note selection, and app switching.

## 📱 Mobile & Telegram Transfer Guide

Because NoteVault compiles into a single, self-contained `index.html` file, you can easily transfer and run it on your smartphone.

### Method 1: Send via Telegram (Offline File)

1. **Send to Telegram**: Send `index.html` (or rename it `NoteVault.html`) from your computer to your Telegram **Saved Messages** as a **Document / File**.
2. **On Android**:
   * Tap the file in Telegram ➔ **Save to Downloads**.
   * Open the file with **Chrome**, **Firefox**, or **Brave**.
   * *(Optional)* Tap the browser menu (⋮) ➔ **Add to Home screen**.
3. **On iPhone (iOS)**:
   * Tap the file in Telegram ➔ Tap the **Share** icon ➔ **Save to Files**.
   * Open the **Files** app on your iPhone and tap `NoteVault.html` to open it in Safari.

---

### Method 2: GitHub Pages PWA (Recommended for Mobile)

1. In your GitHub repository: Go to **Settings ➔ Pages**.
2. Under **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `master` / `/ (root)` ➔ Click **Save**.
3. Open your custom GitHub Pages URL on your mobile phone:
   ```
   https://<your-username>.github.io/notevault/
   ```
4. Tap **Share ➔ Add to Home Screen** to install NoteVault as a standalone app with offline Service Worker support.

## 🔄 Cross-Device Sync Setup

To sync your notes between your PC and Mobile Phone:

1. **Pairing Recovery Words**: When setting up NoteVault on your second device, click **Recover with 12 words** and enter the exact 12 words generated by your first device.
2. **Add GitHub Token**:
   * Go to **Settings ➔ GitHub Token**.
   * Enter a GitHub Personal Access Token (Classic with `gist` scope) generated from [GitHub Settings](https://github.com/settings/tokens).
3. **Automatic Sync**: NoteVault will detect your encrypted Gist, pull down your notes, and keep both devices seamlessly synchronized.

## 🔒 Security & Cryptography

```
                ┌─────────────────────────────────────────┐
                │          User Passphrase                │
                └─────────────────────────────────────────┘
                                     │
                        PBKDF2-HMAC-SHA256 (100,000)
                                     ▼
                ┌─────────────────────────────────────────┐
                │             Passphrase Key              │
                └─────────────────────────────────────────┘
                                     │ (Unwraps)
                                     ▼
┌───────────────────────┐      ┌──────────────────────────┐
│   12 Recovery Words   │ ───> │  Master Recovery Key     │ (AES-256-GCM)
└───────────────────────┘      └──────────────────────────┘
                                     │
                    ┌────────────────┴────────────────┐
                    ▼                                 ▼
      ┌───────────────────────────┐     ┌───────────────────────────┐
      │  Local IndexedDB Storage  │     │   Remote GitHub Gist      │
      │  (Encrypted at Rest)      │     │   (vault.enc)             │
      └───────────────────────────┘     └───────────────────────────┘
```

* **AES-256-GCM**: Every note payload and exported backup is encrypted using authenticated AES-GCM with a fresh 12-byte initialization vector (IV) per write.
* **Salt & Key Derivation**: Passphrases derive keys using 100,000 iterations of PBKDF2 with unique cryptographic salts stored in IndexedDB.
* **Zero Plaintext Transmission**: Notes are encrypted in client memory before touching IndexedDB or GitHub Gist APIs.
